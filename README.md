# ⚛️ Draft React

Коллекция мини-проектов на React 18+ с современным стеком и передовыми подходами.
Создана как демонстрация практических навыков front-end разработки и для использования в портфолио.

Проекты покрывают различные аспекты веб-разработки: от работы с API и локального хранилища до управления состоянием и анимаций.

---

## ⚙️ Стек технологий

- [React 18+](https://react.dev/) — современная библиотека для создания UI
- [Vite](https://vitejs.dev/) — быстрая сборка и dev-сервер
- [Tailwind CSS](https://tailwindcss.com/) — утилитарный CSS-фреймворк
- React Router — маршрутизация и переходы между мини-проектами
- useState / useReducer / Context — для управления состоянием
- Работа с API и localStorage
- Адаптивный интерфейс и анимации

---

## 📦 Проекты внутри

**Notes** — Заметки с локальным хранилищем, редактированием и удалением

**Blackjack** — Мини-игра в блэкджек с колодой от Deck of Cards API

**Currency Converter** — Конвертер валют с публичным API

**User Table** — Таблица пользователей с фильтрацией и выделением строк


## 🧱 Архитектура и особенности

- Использование `useState`, `useReducer` и `Context` для управления состоянием
- Атомарные переиспользуемые компоненты (`Card`, `Button`, `IconBtn`, `Modal` и др.)
- Разделение логики и отображения: контейнеры и чистые компоненты
- Интерактивные UI и мини-игры для демонстрации навыков
- Локальное хранилище
